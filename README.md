# Dynamic Island For Mac

## What is this?
- This is a music interface that works with MacOS. It functions the same as a dynamic island on iPhone, just without a lot of its features.

## Features
- Apple music integration: Shows current song, album art and artist
- Animated equaliser bars and pill
- Expanding interface

## How it works
- it is a borderless always on top window pinned to the centre of the top. styled to look native to MacOS, it polls Apple Music via AppleScript to keep UI responsive. all icons sit directly on a `tkinter` canvas.

## Requirements
- macOS
- Python 3
- Apple music app
- Python packaged pyobjc (for Appkit), Pillow
